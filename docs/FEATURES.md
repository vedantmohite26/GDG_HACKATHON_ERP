# System Features Overview

This document outlines the specific features available to Students and Faculty users within the **Unified Student Welfare & Academic Information System**.

## 🎓 Student Features

Students are the primary beneficiaries of the system, with access to welfare, academic, and administrative tools.

### 1. Profile & Identity
- **Digital Profile**: View personal details, academic history, and contact information.
- **Document Vault**: Securely upload and manage academic documents (marksheets, certificates) for verification.
- **ID Card**: Digital ID card generation with QR code (if implemented) or details.

### 2. Scholarships & Financial Aid
- **Smart Recommendations**: View eligible scholarships based on academic profile and criteria.
- **Application Portal**: Apply for scholarships directly through the app.
- **Application Tracking**: Real-time status updates (Submitted -> Faculty Recommended -> Committee Approved).

### 3. Grievance Redressal
- **Submit Grievance**: Report issues related to academics, facilities, or miscellaneous topics.
- **Anonymous Reporting**: Option to submit grievances anonymously for sensitive matters.
- **Track Status**: Monitor the progress of submitted grievances (Assigned, In Progress, Resolved).
- **Priority System**: AI/Rule-based priority scoring ensures urgent issues are highlighted.

### 4. Academic & Campus Life
- **Notices & Announcements**: Receive real-time official notices (Holidays, Exams, Urgent Alerts).
- **Academic Calendar**: View upcoming events and schedule.
- **Attendance**: View personal attendance records (if student view is enabled).

## 👨‍🏫 Faculty Features

Faculty members play a mentorship and administrative role, facilitating approvals and student management.

### 1. Dashboard & Workload
- **Real-Time Stats**: Live overview of pending tasks, assigned grievances, and documents to verify.
- **Responsive Interface**: Optimized layout for efficient task management on mobile and web.

### 2. Student Management
- **Student Search**: Real-time search to quickly find students by Name, ID, or UID.
- **Student Profiles**: View detailed student academic information and uploaded documents.
- **Mark Attendance**:
    - **Dynamic Filters**: Select Branch -> Year -> Subject -> Date.
    - **Smart Validation**: Prevents errors during attendance submission.

### 3. Applications & Approvals
- **Review Applications**: Review scholarship applications assigned to them.
    - **Recommendation**: Provide "Recommended" or "Not Recommended" status with comments for the Committee.
- **Verify Documents**: Check uploaded student documents and mark them as verified or rejected.

### 4. Grievance Handling
- **Assigned Grievances**: View and manage grievances specifically assigned to them by the Committee.
- **Status Updates**: Update grievance status (e.g., set to "In Progress" or "Resolved") and add internal notes.

### 5. Communication
- **Post Notices**: Authority to create and post notices for students (General, Urgent, Holiday).

---

## 🛠 Admin & Committee Features (Reference)

While not requested, these roles oversee the system:
- **Admin**: Full system control, user management, audit logs, and global statistics.
- **Committee**: Final approval authority for scholarships, assigning grievances to faculty, and high-level decisions.
